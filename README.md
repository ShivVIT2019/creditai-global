# 💳 CreditAI Global - Smart Credit Approval System

AI-powered credit assessment system for **USA** 🇺🇸 and **India** 🇮🇳

## 🎯 Features

### 🇺🇸 USA Credit Assessment
- Trained on 2.2M real loans from Lending Club
- 86%+ ROC-AUC accuracy
- Supports: Visa, Mastercard, American Express, Discover

### 🇮🇳 India Credit Assessment  
- CIBIL score-based evaluation
- PAN & Aadhaar verification
- City tier consideration
- Supports: Visa, Mastercard, RuPay, American Express

## 🚀 Run Locally
```bash
pip install -r requirements.txt
python app.py
```

## 🤖 Technology
- Algorithm: Random Forest Classifier
- Framework: Gradio
- Dataset: 100,000+ loan applications
- ROC-AUC: 86.5%
